## 🛠️ Troubleshooting Common Questions

**Q: I see a Windows SmartScreen warning when I open the app. What do I do?**  
A: That's a standard Windows check for unrecognized apps. Since this is a community-built tool, it hasn't gone through Microsoft's commercial certification. Click "More info" then "Run anyway". It's safe.

**Q: The app opens but shows a blank screen.**  
A: Close it and reopen. If the problem persists, check that you extracted the ZIP completely (not just opened it). You must run the EXE from inside the extracted folder.

**Q: Can I move the dashboard to another computer later?**  
A: Yes. Copy the entire data folder (Settings → Data Folder Location) to a USB stick. On the new computer, install the app and during setup point it to that folder.

**Q: Is there a mobile app?**  
A: Not yet, but the desktop version works great on Windows tablets and touchscreens.
